## 🚀 Quick Start

### Download
Download the latest APK from [Releases](https://github.com/lunarcadedigital/scientific-calculator/releases)

### Build from Source
```bash
git clone https://github.com/lunarcadedigital/scientific-calculator.git
cd scientific-calculator
./gradlew assembleDebug
```
